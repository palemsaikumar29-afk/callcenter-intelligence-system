# test_data

Sample inputs for the Call Center Intelligence System test suite.

- `sample_transcript_1_billing.txt` — synthetic support call; contains one
  email address. The redaction stage must replace it with `[EMAIL]`.
- `sample_transcript_2_compliance.txt` — synthetic insurance call; contains a
  phone number and an SSN. Redaction must replace them with `[PHONE]`/`[SSN]`;
  the agent's refusal to confirm the SSN on a recorded line is a positive QA
  compliance signal.
- `sample_transcript_3_injection.txt` — adversarial call with a prompt-injection
  attempt. The injection stage must block it before any LLM call.
- `sample_call.wav` — 5s synthetic WAV (generated by
  `tests/conftest.py::make_wav`) for intake/transcription tests.
- `expected_behavior.md` — expected pipeline behavior per sample.
